# ecom-microservices
Building e-commerce application using spring boot and microservices, using apache kafka, rabbitMQ, Docker and kubernates while building application 

IMPORTANT STEPS WHILE CONFIGURING APPLICATION
==============================================
configure {.env} file into Intellij environment variable in Edit configurations (i.e setting Environment Variable)

Install docker desktop and run containers to connect to postgresql database

Install mongo server & mongoDB compass softwares in  local to work with mongoDB

RabbitMQ is run on the docker container where rabbitMQ image is taken from remote repository
